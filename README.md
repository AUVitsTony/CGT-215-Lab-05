# CGT-215 Lab 05

This lab is a C++ program that takes text entered by the user and translates it using a custom cypher.

## Lab 05

This lab focuses on using vectors, strings, loops, functions, and character values to create an encoded message.

This lab uses:

- `cin` and `getline()` for user input
- `cout` for output
- `string` to store the user's message
- `vector<char>` to store the cypher
- A separate function called `cypherTranslation`
- A `for` loop to go through the text one character at a time
- `if` and `else if` statements to check uppercase and lowercase letters
- ASCII character values to work with letters
- Basic character conversion between uppercase and lowercase
